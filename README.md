# بوت خبير وتداول مؤشر US500 المؤسسي المتكيف (US500 Institutional Trader)

نظام متكامل لتداول مؤشر **S&P 500 (`US500`)** يدمج بين **بيانات Capital.com المباشرة** و **تيليجرام** مع نظام تكيفي شامل يتأقلم مع جميع ظروف السوق وتدفقات الأوبشن CBOE.

---

## 🎯 الاستراتيجيات الأربع المتكيفة (Multi-Regime Portfolio)

1. **[B] سحابة إيشيموكو وبولينجر 4H (Jesse Ichimoku Cloud Breakout):**
   - **الهدف:** ركوب موجات الاتجاه المؤسسي الصاعد فوق متوسط 200 يوم.
2. **[C] قنص كنس السيولة 4H (SMC Liquidity Sweep):**
   - **الهدف:** اصطياد فخاخ الدببة وصناع السوق عند كسر قاع 30 شمعة ثم الارتداد.
3. **[A] اختراق دونشيان اليومي 55 (Donchian 55 Daily):**
   - **الهدف:** اقتناص انطلاقات الدورات السعرية الكبرى بعد كسر قمة 55 يوماً.
4. **[D] قنص تدفق السيولة المؤسسية (Institutional Shadow Flow):**
   - **الهدف:** اصطياد التجميع والتصريف عبر MFI عند حواف بولينجر باند.

---

## ⚡ الميزات التقنية
- **إدارة الجلسات في كابيتال (Session Caching):** منع خطأ 429 والحفاظ على استقرار الاتصال.
- **إدارة المخاطر الصارمة:** حساب حجم اللوت تلقائياً بحيث لا تتجاوز الخسارة 1% من الرصيد.
- **تأمين الوقف التلقائي (Break-Even):** تحريك الوقف إلى نقطة الدخول عند وصول السعر إلى `+1.0R`.
- **معنويات المتداولين (Capital Sentiment):** قراءة حية لنسبة المشترين والبائعين على المنصة لـ US500.
- **رادار الأوبشن المؤسسي CBOE (GEX & Walls):** مراقبة جدران الكول والبوت ومستويات تعرّض الغاما.
- **شارت شموع يابانية مباشر:** توليد شارت عالي الدقة يوضح المتوسطات ونقاط الدخول.
